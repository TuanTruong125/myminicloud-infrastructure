Kiểm tra file zone đã có record mới
Mở file db.cloud.local
Cần thấy các dòng:
app-backend IN A 10.10.10.20
minio IN A 10.10.10.30
keycloak IN A 10.10.10.60
Restart DNS container để nạp lại zone
Chạy lệnh:
docker restart internal-dns-server
Test trực tiếp bên trong DNS container bằng dig (chắc chắn nhất)
Chạy lần lượt:
docker exec internal-dns-server sh -lc "dig @127.0.0.1 app-backend.cloud.local +short"
docker exec internal-dns-server sh -lc "dig @127.0.0.1 minio.cloud.local +short"
docker exec internal-dns-server sh -lc "dig @127.0.0.1 keycloak.cloud.local +short"

Kết quả mong đợi:

10.10.10.20
10.10.10.30
10.10.10.60
Test từ máy host (Windows) qua cổng publish 1053
Vì compose map 1053:53/udp, dùng:
nslookup app-backend.cloud.local 127.0.0.1
nslookup minio.cloud.local 127.0.0.1
nslookup keycloak.cloud.local 127.0.0.1

Nếu host không query được do cổng DNS mặc định 53, ưu tiên dùng cách số 3 để chấm bài (dig trong container).

Test caching DNS (phần kiến thức)
Chạy 2 lần cùng một lệnh dig:
docker exec internal-dns-server sh -lc "dig @127.0.0.1 app-backend.cloud.local"
Lần sau thường Query time thấp hơn.
Nếu vừa sửa zone mà kết quả chưa đổi, restart lại container DNS hoặc tăng serial trong db.cloud.local.
