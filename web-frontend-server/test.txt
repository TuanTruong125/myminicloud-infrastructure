Test bằng Postman

Tạo request:
Method: GET
URL: http://localhost/
Ở phần response, kiểm tra Headers:
X-Load-Balancer: Round Robin
X-Backend: sẽ đổi giữa 2 IP nội bộ khác nhau
X-Instance: sẽ đổi giữa web-frontend-server1 và web-frontend-server2
Bấm Send nhiều lần liên tiếp, kỳ vọng luân phiên:
Lần 1: X-Instance = web-frontend-server1
Lần 2: X-Instance = web-frontend-server2
Lần 3: X-Instance = web-frontend-server1
Lần 4: X-Instance = web-frontend-server2
Nếu chưa luân phiên, restart proxy rồi test lại:
docker restart api-gateway-proxy-server
2. Test trên giao diện web (trình duyệt)

Mở http://localhost/
Mở DevTools -> Network -> chọn request /
Xem Response Headers:
X-Load-Balancer
X-Backend
X-Instance
